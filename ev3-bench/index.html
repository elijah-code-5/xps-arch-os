Ctrl+Enter runs
Commands 
drive(left, right)        both drive motors, -100 to 100
stop()                    stop all motors
await move(cm, speed)     drive straight, negative = reverse
await turn(deg, speed)    spin in place, positive = right
await wait(ms)            pause (use it inside every loop)
await until(() => test)   wait until test is true
touch()  distance()  color()  reflect()  heading()
gyroReset()               zero the gyro
motor('A').run(speed)     motor('A').stop()  motor('A').position
log(...)                  print to the console below

Changes reset the robot to its start spot.
